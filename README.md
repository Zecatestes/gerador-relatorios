# Gerador de Relatórios Odeen

Aplicação desenvolvida para facilitar a criação de relatórios de recuperação de veículos, permitindo preencher informações, anexar imagens como evidências e gerar documentos em PDF.

## Como utilizar

1. Acesse a opção **Novo relatório**.
2. Preencha as informações solicitadas sobre a ocorrência e o veículo.
3. Anexe imagens, caso necessário.
4. Confira os dados e gere o relatório em PDF.
5. Utilize a opção **Formalizador Faster** para acessar a ferramenta de formalizações padrões.
